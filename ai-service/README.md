# FitFlow AI Service

This folder represents the artificial intelligence features of the FitFlow application.

## Selected Technologies

- TensorFlow Lite
- ML Kit
- Optional Python FastAPI cloud service

## Main Responsibilities

- Generate personalized workout recommendations
- Adapt workout plans to the user's schedule
- Support exercise recognition
- Support camera-based food recognition
- Provide reasons for AI recommendations
- Allow users to confirm or correct AI results

TensorFlow Lite and ML Kit can perform suitable AI tasks on the device. A separate FastAPI service may be introduced later if more advanced cloud-based AI processing is required.
