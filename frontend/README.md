# FitFlow Frontend

This folder represents the React Native mobile application and React Native Web frontend of the FitFlow system.

## Selected Technologies

- React Native
- Expo
- React Native Web

## Main Screens

- AI-First Home Dashboard
- AI Workout Planner
- Nutrition Logger
- Community Feed
- Progress Tracking

## Lab 4 Improvements

The frontend should include clear action labels, an acceptance confirmation, a shorter onboarding process, manual food correction, visible community privacy information and larger progress-chart text.
