# FitFlow Backend

This folder represents the Node.js and Express backend of the FitFlow application.

## Selected Technologies

- Node.js
- Express
- Socket.IO

## Main Responsibilities

- Manage user profiles
- Generate and manage workout plans
- Store nutrition records
- Manage progress and badges
- Manage private groups and challenges
- Verify Firebase authentication tokens
- Provide real-time community updates
- Send notifications
